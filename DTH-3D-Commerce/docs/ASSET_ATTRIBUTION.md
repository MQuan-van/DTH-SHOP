# 3D asset provenance

All newly supplied files under `frontend/public/models/dth-demo` and `frontend/public/previews/dth-demo` were generated for this implementation using `tools/make_assets.py`.
There are five original procedural geometry families and four variants in each family. No manufacturer mesh, photograph, logo, commercial review or scanned part was downloaded for these assets.
The previews are software renders of the corresponding generated geometry. The GLBs use local geometry/materials, without external textures or HDR dependencies. Meshes sharing the same material are combined; each generated file contains at most four mesh objects.

The assets are illustrative placeholders for a student demonstrator, not dimensionally verified designs. Naming, finish descriptions, prices and vehicle mappings are synthetic. Do not use these meshes for manufacturing, safety assessment or installation decisions.

The original repository's Story/Home/Gallery assets are not copied into this bundle and their existing attribution/licensing status is not assessed here.

For replacement assets, add a record for each file with author, exact source, license/version, permitted modifications, attribution wording, download date, changes made and product ID. An API path restriction does not verify licensing or real fitment.
